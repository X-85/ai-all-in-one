# 待办清单(用户侧)

> 层:工作文档 | 性质:专题剩余事项的统一入口——需要你本人输入/执行的项目,按优先级排列 | 更新:2026-10-01

一句话版:**AI 能代劳的已全部完成;这个清单里每一项都需要你本人动手,做完任何一项,回会话说对应口令即可继续。**

使用说明:直接编辑本文件勾选;或完成后在会话里说对应口令,由 AI 回填并更新下游文档(复盘/故事库/质量层/站点)。**P0 是数据源头,优先级高于一切 P1。**

## P0 · 数据源头(公司项目,喂三个下游)

**A. 公司六步清单**(完整版见 knowledge/doc/RAG问答系统质量设计-问答记录与落地方案.md 第五节,此处为勾选视图):

- [ ] ①拉真实问题 ≥30 条并标注预期路由(A/B/C/D)——产出即 golden set v0
- [ ] ②答案之书 v0(10+ 条,格式:问题/标准答案/别名问法/验证日期/时效提示)
- [ ] ③AstrBot 配置(答案之书独立库带 verified / persona 写入四路由规则)
- [ ] ④首轮回归(golden set 逐条测,记录"问题-预期路由-实际路由-结果"对照表)
- [ ] ⑤定阈值与误路由分析(专名类/否定类单列统计)
- [ ] ⑥立飞轮(每周五 30 min 审核沉淀)

完成后口令:**"六步清单跑到第 X 步了,数据如下:…"**
下游:RAG 复盘 7 个占位 → 质量层开写 → 简历量化指标 → 故事库 D2 卡

## P0 · 横评口述回填(碎片时间,喂两个下游)

- [ ] codex / [ ] pi coding agent / [ ] codebuddy / [ ] zcode / [ ] zed / [ ] claude code(每工具约 30 分钟)

完成后口令:**"帮我填横评的 <工具名> 部分"**(AI 按八问引导,你口述即可)
下游:对比表+选型决策树生成 → 工程层第三篇闭环 → 故事库 D1 卡 → 简历技能行实料

## P1 · 占位回填类(有数据后随手给)

- [ ] RAG 复盘 7 个 `[待回填]`(第八节有汇总表,公司数据到手即填)
- [ ] 简历量化指标(周提问量/用户规模/bad case 修复数)
- [ ] 个人背景:工作年限、当前岗位、教育背景(技能地图与简历要用,涉及未知处一律没敢编)
- [ ] 故事库 D3:AI 治理实战细节(方法论文档有了,缺你的实战经历)

## P1 · 执行类(checklist 落地,无需数据即可启动)

- [ ] AstrBot 源码深读三周计划启动(第 1 周:跑起来读架构三处)——完成后口令"深读笔记第 1 周"
- [ ] 公开输出渠道二选一:掘金 / 知乎(定了就位,初稿 AI 可代劳)
- [ ] 10 月末:时间线核对打分(checklist 第五节)

## P2 · 可选(不阻塞主线)

- [ ] Q6 公司试点效果回填(带了 ZCode 手册去公司的实测——台账 Q6 也挂着)
- [ ] 演进系列二三梯队按兴趣续写(Nginx/ES/MongoDB/Git 等,纯兴趣线)
- [ ] Cloudflare Pages 自定义域名决策(Q3,与求职无关)

## 建议节奏(每周 ~3 小时投入的参考分配)

| 时段 | 动作 |
|------|------|
| 工作日碎片(30 min×2) | 横评口述一个工具 |
| 周五(30 min) | 飞轮审核 + 新误路由补进 golden set |
| 周末(60~90 min) | 六步清单推进 / AstrBot 深读 / 占位回填 |

## 给 AI 的状态同步口令(存档)

任意时点回来,一句即可恢复上下文:**"看台账 Q8 继续"**——AI 会读本清单与台账,接着推进。
