## 术语对齐(面试前必扫)

行业黑话 ↔ 本专题自建语言的映射。面试官用词问,你按对应内容答——有货说得出:

| 行业术语 | 一句话 | 本专题对应位置 |
|---|---|---|
| context engineering(上下文工程) | 设计"什么信息、什么形式、什么时机进入窗口"的信息流水线;提示词工程是其子集 | **专题篇:[LLM基础认知-上下文工程](LLM基础认知-上下文工程.md)**(三约束→六族方案+实践对照);机制:生成机制(上)·一、(下)·一 |
| prompt engineering(提示词工程) | 上下文工程的子集,只管静态指令层 | 上下文工程·三·5(结构化与位置族);复盘六(模板/persona) |
| harness engineering | 给模型配齐运行环境:工具、权限、反馈回路、验收 | 工作流篇八条通用模式(受控工具/验收前置/过程留痕/只读侦查)即一张 harness 清单 |
| agentic RAG | 检索是工具、多轮状态、"答还是问"自主决策 | 复盘一/五(四路由系统即其实现) |
| evals / golden set / LLM-as-judge | 评测集、回归、模型评模型 | 质量层规划 + Q7 评估闭环(六步清单④⑤) |

## 生成机制(上)的延伸点

- **分词器家族**(BPE / WordPiece / Unigram / SentencePiece / byte-level):不同切法的取舍与中文影响。触发:做中文场景 tokenizer 选型,或发现分词差异影响效果时
- **采样策略全集**(top-k / min-p / 重复惩罚 / 频率惩罚):正文只讲了 temperature 与 top-p。触发:调参解决复读机、风格失控时
- **Logprobs**:把每步的候选概率拿出来,可做置信度估计、分类器、异常检测。触发:要做"模型不确定度"相关功能时
- **解码策略**(贪心 / beam search):为什么开放生成不用 beam search 穷举最优路径。触发:被面试官追问"为什么不选全局最优"
- **幻觉检测与分类**(事实性幻觉 vs 忠实度幻觉;自洽性采样检测):触发:质量层要做幻觉监控时
- **上下文学习 ICL**(in-context learning):为什么几个示例放进上下文就能改变行为。触发:被问"in-context learning 和微调有什么区别"

## 生成机制(下)的延伸点(下篇已成稿,以下为占位)

- 注意力机制原理(QKV / O(n²) 复杂度):触发:想讲清"为什么长上下文贵"
- KV cache 与推理成本:触发:算延迟账、优化吞吐时
- 推理模型训练路线(RL 路线 / thinking budget):触发:普通模型 vs 推理模型选型被深挖
- 思考链忠实性(CoT faithfulness):thinking 文本不一定反映模型真实决策过程;触发:想给用户直接展示 thinking 内容时
- 后训练细节(SFT 数据从哪来 / reward model / DPO):触发:微调选型被深挖
- 蒸馏与量化:触发:私有化部署选型时
- 多模态前端(视觉编码器 / 图像 token 化):触发:做多模态 RAG(截图问答)时
- MoE 架构:触发:模型选型与成本对比时

## 检索原理的延伸点(检索篇已成稿,以下为占位)

- ANN 算法(HNSW / IVF / PQ):触发:向量库选型与调参时
- 双塔 vs 交叉编码架构细节:触发:想讲清 rerank 为什么准、或被追问两种编码的结构差异时
- embedding 训练(对比学习):触发:embedding 模型选型被问原理时
- BM25 与混合检索融合(RRF):触发:关键词命不中、要上混合检索时
- 图谱与向量结合(GraphRAG):触发:多跳问答效果差时
- 语义缓存:触发:成本优化专项时
