# AGENTS.md(ai-career-notes/)

本目录是独立专题:**AI 应用工程岗求职技能整理**(2026-09-30 启动)。

## 这个目录是干嘛的

用户以 AI 应用工程岗为目标岗位,在 2027 年年后求职。本目录把用户一年多的 agent 实战经验(codex / pi coding agent / codebuddy / zcode / zed / claude code)、FAQ 问答 RAG 系统实践(钉钉 + AstrBot)、以及本知识库的文档产出能力,整理为四层框架(原理 20% / 工程 30% / 质量 20% / 证据 30%),核心动作是**体系化 + 证据化**:散落的经验变成能讲的知识,会的东西变成可展示的作品与指标。

## 处理本目录任务前必读

1. 本目录 `AI应用工程岗技能地图.md` —— 主干文档,四层框架、时间规划、后续文档清单都在里面,任何新文档先对照它的第六节规划
2. 根目录 `session/decisions.md` —— 全仓库长期约定(讲事实不编造等原则同样适用本专题)
3. `session/index.md` 的 Q8 —— 本专题的台账进度

## 写作约定

- 命名:中文望文知义,如 `Agent编码工具横评.md`;主干文档唯一,子文档按技能地图第六节规划扩展,新主题先在主干第六节登记再动笔
- 内容原则:讲事实不编造——用户没说过的个人体验/数据留占位符让用户回填,不替用户编造;工具横评、面试故事等"独有素材"类内容必须来自用户真实经历
- 互链:本目录内文档互链写相对文件名;引用目录外文档用仓库相对路径(如 `../knowledge/doc/RAG是什么.md`)——站点构建时前者转站内路由、后者转 GitHub 源文件页。本目录已接 `ai-career-notes-site/` 站点(部署在 `/ai-all-in-one/career/`,AGENTS.md 不发布),新文档需在 `ai-career-notes-site/src/chapters.ts` 加条目并补首页 descriptions
- 涉及用户个人信息(工作年限、当前岗位、教育背景等)未知时,写 `[待回填:xxx]`,不要推测

## 台账

会话台账协议照常(见根 AGENTS.md):每轮结束追加 `session/events.md`、更新 `session/index.md` Q8 行,回复末尾附 [台账更新] 尾注;稳定约定写入 `session/decisions.md` 第 8 节。
